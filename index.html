REDIRECTING CONSTRUCTORS
Implementasi konsep Redirecting Constructors pada kelas Circle dalam Dart. Konstruktor utama validasi radius positif, lalu tiga konstruktor alternatif fromDiameter, fromKeliling, dan fromLuas langsung mendelegasikan ke konstruktor utama tanpa duplikasi kode (prinsip DRY).
📘 lib / circle.dart

import 'dart:math' as math;

class Circle {
  final double radius;

  Circle(this.radius) {
    if (radius <= 0) {
      throw ArgumentError('Radius harus positif!');
    }
  }

  Circle.fromDiameter(double d) : this(d / 2);
  Circle.fromKeliling(double kel) : this(kel / (2 * math.pi));
  Circle.fromLuas(double area) : this(math.sqrt(area / math.pi));

  double get diameter => radius * 2;
  double get keliling => 2 * math.pi * radius;
  double get luas => math.pi * radius * radius;

  @override
  String toString() => 'Circle(r:${radius.toStringAsFixed(2)}, '
      'd:${diameter.toStringAsFixed(2)}, k:${keliling.toStringAsFixed(2)}, L:${luas.toStringAsFixed(2)})';
}
